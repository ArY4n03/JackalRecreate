

## 🎮 About the Project
This project was created while learning **Unity game development**.  
The goal was to understand and practice core game development concepts by building a small **top-down shooter** with multiple levels.


## 🕹️ Gameplay Features
- Top-down movement
- Shooting mechanics
- Enemy waves
- 3 playable levels
- Simple progression system

---

## 🛠️ Built With
- **Unity Engine**
- **C#**

---

## 📁 Project Purpose
This project is **non-commercial** and was made **purely for learning and educational purposes**.

It serves as:
- A practice project
- A learning milestone
- A portfolio demonstration of Unity basics
